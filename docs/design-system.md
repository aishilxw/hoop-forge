# Hoop Forge 视觉与交互规范 v1

方向：篮球球探工作台＋原创球员卡收藏册。深色底、暖白字、橙色主操作，绿色为成长/胜利，红色为错误/失利。颜色、圆角、间距均在src/styles/global.css的:root中冻结。

GameView为唯一根页面，接收reactive GameAPI；所有状态变更通过api.execute，组件不计算奖励、抽样、比赛和余额。DraftBuilder仅计算预览，不提交前不会消耗。卡片选择可键盘操作，无拖拽依赖。九维顺序直接使用ATTRIBUTE_KEYS。

共享组件：BaseButton(四种variant)、BaseDialog(原生dialog/Esc/归还焦点)、StatBar、AttributeGrid、RadarChart、PlayerCard、CoinBadge、EmptyState、InlineAlert、ToastRegion、AppShell。字体全部本地系统字体，不加载外部图片和字体；球衣为原创SVG/CSS图形。

桌面224px导航栏（窄桌面折叠）、最大1512px内容，手机顶部导航。基准视口1440×900、1024×768、390×844。手机创建页把能力槽置于卡库前，保持点击选择可见；不强制雷达图作为唯一数值表达。

主要状态：无存档首页、draft创建、ready赛季中心、result结果、seasonSummary总结、offseason休赛、finished生涯归档。卡库和商店保留独立tab。每次命令phase改变返回生涯tab。只读页/数据未verified持续显式提示。

人工验收尚未执行：需Lead接线并启动后，在三个视口验证无横向溢出、卡片长名、所有命令闭环、键盘焦点、弹窗返回焦点。构建通过不等于视觉验收。

## v0.2 NBA生涯修订

- 所有球员卡都是盲选：固定抽取顺序，隐藏单项与综合评分，不利用排序、禁用按钮、雷达图或提升预览间接泄露来源评分。
- 创建前九槽只显示中文来源姓名与选择状态；确认创建后才显示原创球员数值。
- 候选继承卡不预告是否更强；确认明确说明消耗整卡且可能无提升，执行后弹窗揭晓实际变化。
- 创建页真实30队选择与名单概览。生涯中心统一展示分区战绩、82场进度、主客场、联盟排名、季后赛系列赛和更衣室名单。
- 生涯报告属于游戏内可阅读内容：分阶段效率表、职业分析、代表比赛、逐季成绩、成长谱系。存档备份是独立顶栏功能，不代替报告。
- 未接入运行时AI时，报告标为“统计分析报告”，不声称模型生成。未来AI文字追加到既有统计事实之上。
- 实际赛程来源标记必须如实展示；生成赛程不能伪称官方逐日赛程。

## v0.3 场边战术观战

- 继续采用深底、橙色本队、浅蓝对手，原生SVG球场与比分走势图，不使用外部素材或3D依赖。
- 比赛状态为：赛前布置 → 本节真实事件回放 → 节末数据与战术调整 → 下一节；第四节含加时也先回放后揭晓胜负。
- 球场上十个标记使用当前事件的真实阵容ID；球、投篮轨迹、事件文案、比分均来自已经计算和展示的回合。仅为战术示意，不声称连续物理动画。
- 不提前展示本节未来比分、走势、box score或奖励。Q4结算时顶栏隐藏金币，避免通过奖励反推胜负。
- 默认2倍播放，可暂停、逐回合、1/2/4倍、跳到节末和减少动画。未播完可跳过，但不能同时提交下一节；重新载入直接恢复已完成节末。
- 每季8场自动重点比赛，其他比赛也可主动观战或快速模拟。战术控件说明收益与代价，不提示必胜组合。
- 选择项包括进攻、防守、节奏、轮换、原创球员分钟预算与重点球员；通过统一命令入口提交，UI不修改概率或比分。
- 生涯中心显示年龄和身体状态；休赛期先规划，再进入下一年。退役需要确认，完整档案保留。
- 新增罚球、犯规栏；历史缺失值采用0兼容，不能出现NaN或undefined。

## v0.3.3 展示信息层级（取代旧版全页资料横幅规则）

按用户要求减少开发状态和未完成语气。partial资料保持实际状态，范围/来源/单人差异及估计比例集中在关于游戏；卡面仍保留估计评分标记。fixture样例与只读警告仍须显式提示，不可把样例冒充真实资料。主页面只突出球员、赛程、成长和下一步操作，移除迁移日志展示但不删除存档记录。AI信息保留生成来源与主动发送说明，技术用量保持折叠，缓存不写成模型重新生成。

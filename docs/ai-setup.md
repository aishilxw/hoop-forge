# DeepSeek AI 生涯故事

用户已选择 DeepSeek V4.1 Flash。官方接口名是 `deepseek-flash`，地址为 `https://api.deepseek.com/chat/completions`。官方目前将其指向V4.1 Flash系列；别名后续可能更新，不宣称固定权重快照。参考：https://api-docs.deepseek.com/en/ 、https://api-docs.deepseek.com/guides/json_mode/ 。

## 本地试玩包

基础游戏不需要密钥或联网。v0.3.4 面试试玩包已连接共享 AI 服务，联网后可直接使用生涯故事与 AI 教练，无需自己的密钥或登录。需要 Node.js 24，启动方式不变。

共享服务有效期至北京时间2026-11-29 13:19:53；累计最多500次模型请求，每天100次，每份安装每天30次、每分钟6次，同时最多3次在途请求。失败请求也保守计入，命中缓存不新增请求。这是网关调用上限，不代表模型账户费用上限。

模型密钥仅存于云端 Secret。包内 review.config.json 只有地址和可撤销试玩标识；该标识可提取，并非强身份认证，持有者可能消耗共享额度。云端 REVIEW_ENABLED 可关闭服务，更新 REVIEW_BUILD_ID 可撤销旧包。修改额度或有效期需更新云端环境并部署，不要修改 REVIEW_SESSION_ID 绕过既有累计记录。

云端只接收固定报告与教练任务，保存请求计数、哈希化安装标识和24小时结果缓存。游戏材料和缓存正文可能包含玩家填写的球员名，不发送完整存档或未来赛果。到期、额度用尽或断网时仍可继续基础游戏与手动战术。

## 可选：自己的模型账户

共享模式优先。若要使用自有密钥，增加 HOOP_FORGE_AI_MODE=local：

在解压后的 `start.mjs` 同一目录创建 `.env.local`（不要分享该文件）：

```dotenv
HOOP_FORGE_AI_MODE=local
DEEPSEEK_API_KEY=替换为你自己的密钥
DEEPSEEK_MODEL=deepseek-flash
```

然后运行 `node start.mjs`，打开固定的 `http://127.0.0.1:4178`。更改密钥后重启服务。也可使用环境变量，或 `node --env-file=/你的私有配置路径 start.mjs`；不用把配置放进游戏目录。

完成至少一场比赛后，在“生涯报告”选择完整生涯或某一赛季，再点击“生成我的AI生涯故事”。点击之前页面会说明发送给DeepSeek的数据。密钥从本机服务读取，不传给页面，不进入生涯JSON备份或报告缓存。基础统计始终可以阅读。

## 源码开发

先 `npm ci` 和 `npm run build`。可使用 `HOOP_FORGE_DIST=dist node --env-file=/你的私有配置路径 scripts/release/start.mjs` 启动本地构建及AI服务。另开 `npm run dev` 时，Vite会把 `/api` 转发到本机4178服务。

## 数据、调用和缓存

- 仅发送已结算比赛的汇总、常规赛/附加赛/季后赛拆分、最多三场代表比赛、逐轮征程、归档赛季、当前九维能力与最近成长记录。报告材料不含完整存档、密钥、隐藏候选卡值或未发生的比赛；接口认证由本机服务处理。
- 完整生涯/当前赛季中的年龄能力明示为当前信息；已归档赛季取末次比赛快照，缺失年龄不猜测。旧赛季沿用冻结名单，不让AI编造真实未来交易。
- JSON模式及程序校验保证结构、字段范围和引用id合法，不保证自然语言完全无误。每段可展开事实依据；统计页为准。
- 只有主动点击才请求模型。相同事实在服务进程内去重/缓存；生成结果另外保存在浏览器IndexedDB。刷新或重新打开相同范围直接读取，不再次付费请求。
- 完整生涯/当前赛季的后续比赛、范围、能力成长变化会改变材料指纹；已归档赛季不受未来成长影响，无需反复付费生成。没有自动付费重试。
- AI正文缓存独立于生涯存档，暂不包含在导出的JSON中；换浏览器或清理站点数据后不会自动恢复正文。
- 故障、余额不足、超时、格式/引用错误显示原因，保留游戏与统计报告。生成最长等待约一分钟。
- 本地服务只监听127.0.0.1；接口限制请求大小、来源和并发。共享模式连接云端服务，自有密钥模式直接连接DeepSeek。

发布前不得包含 `.env.local`、其他环境文件或私有配置。用户曾在聊天里发送密钥，建议在官方控制台轮换，本文不记录密钥。

## 使用场边AI教练

进入战术观战，在赛前或看完一节后点击“询问AI教练”。查看局势、推荐计划、理由与代价后，可点击“采用建议，填入战术板”，也可手动调整。只有点击开始/执行下一节才推进比赛。旧建议不会在下一节继续生效；刷新可恢复当前节已缓存建议。

教练仅发送已完成节的统计和少量阵容摘要，不发送未来结果或随机种子。重点候选排除六犯球员，AI不能指定未提供的球员。没有接口仍可自行布置战术。

同一个DeepSeek密钥同时支持报告和教练，任务通过不同提示词和输出校验区分，没有训练新的模型权重。每次实际生成的token/耗时可展开查看；缓存阅读不新增模型请求，具体费用以DeepSeek账单为准。

## 复现优化评测

有配置且愿意承担测试调用费用时，执行node scripts/evaluate-ai.mjs，读取DEEPSEEK_API_KEY环境变量。完整评测两个档案、每个原版/新版各一次，共四次模型请求；设置AI_EVAL_MODE=optimized可复用已保存基线，只发起两个新版请求。不会自动重试或打印密钥。结果是小样本对照，不是全部生涯的质量或省费保证。

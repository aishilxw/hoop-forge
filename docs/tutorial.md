# 把不同球星的天赋拼成一个人，他能夺冠吗？

看球时，我们总会讨论：如果一个人有某位后卫的组织、另一位球星的投篮，再加上顶级内线的护筐，会打出怎样的生涯？篮球融合生涯把这个问题做成了一个可以反复尝试的游戏。你不用操控摇杆，也不用学习复杂编辑器，而是凭自己对球员的理解，创造球星、选择球队、决定战术，再看比赛和成长如何展开。

## 一、打开游戏，领取你的第一批球员

[点击在线试玩](https://hoop-forge-play.artfulpika132.chatgpt.site)，无需下载、登录或配置模型。喜欢在本地玩，也可以按仓库README安装Node.js 24，构建并启动游戏。

点击“抽取我的20位球员”，你会拿到5位明星与15位其他球员。它们不是完整阵容，而是创造原创球员的天赋来源。卡面只给出身份和资料类型，能力值与总评先隐藏，不按强弱排序。选择靠你的判断，普通球员也可能在某个单项上特别适合。

## 二、九张不同的卡，拼出你的球星

右侧有内线得分、外线得分、内线防守、外线防守、组织、运球、速度、身体、篮板九个能力槽。先点一个槽，再选贡献该项能力的球员。每张卡只能负责一项，因此你需要考虑机会成本：一位球员能做好几件事，究竟把他留给哪一项？

完成九项选择后，给原创球员取名，从30支NBA球队里选择职业起点，再选择初始打法。确认前可以调整；确认后消耗九张卡，其余十一张进入卡库，此时才揭晓原创球员能力。你的球员加入所选球队，和冻结名单中的队友一起开始赛季。

## 三、先经历比赛，再看统计

每支球队都有82场常规赛、41主41客。联盟排名随比赛推进，分区前六直接进入季后赛，七到十名通过附加赛争取最后两个席位。季后赛是四轮七局四胜，主场安排按2-2-1-1-1进行。

不想逐节参与时，可以快速模拟。每季也会提示八场重点比赛，任何未开赛的场次都能主动进入战术观战。这里看的是游戏事件与示意动画，不是真实比赛录像：比分、投篮路线、回合播报和赛后技术统计来自同一份模拟结果。

## 四、在节间作出自己的决定

战术席可以选择进攻方式、防守重点、比赛节奏和轮换，也能设置原创球员26、32或38分钟预算，以及重点使用的本队球员。比如外线拉开会增加三分机会，收缩护筐会改变防守取舍；不同选择都有收益与风险，不是按下某个选项就必胜。

播放可以暂停、单步、倍速或跳到节末。已完成的节会保存，未来回合不会提前显示。前三节不发奖励，终场及必要加时结束后统一结算。个人犯规、六犯离场、位置轮换与体能也会影响比赛。

## 五、让AI成为另一位观察者

赛前或节间点击“询问AI教练”，它会根据当前已知局势和阵容提出下一节计划、理由及代价。点击采用只把建议填入战术板，仍由你决定是否执行，也可以继续修改。它看不到未来赛果，不会替你完成比赛。

有了已结算比赛后，可以进入生涯报告，选择完整生涯或某一赛季，生成自己的篮球故事。每段分析都能展开事实依据，常规赛、附加赛和季后赛统计也分别展示。AI叙事是对游戏记录的解读，精确数值以统计为准；一场高光不会被当成整个赛季的结论。

共享AI需要联网，并受README中公开的额度和有效期限制。到期或服务不可用时，基础游戏、统计报告和手动战术仍然可以使用。

## 六、用一季表现，换下一季的可能

比赛奖励金币，你可以继续抽卡、继承能力、训练，观察新的能力组合是否改善表现。不要只盯综合能力，先看命中率、助攻、失误、体能与具体对手，再决定是加强长处还是补短板。

赛季结束后，逐季记录会留下战绩和季后赛征程。你可以继续下一年，经历年龄成长与衰退，也可以主动退役。比赛是简化篮球模拟，名单和评分有明确来源边界；之后的赛季沿用冻结名单，不冒充真实未来交易。

最后记得备份：进度保存在当前浏览器里，清理数据或换设备不会自动同步。通过“备份存档／导入存档”迁移你的生涯。现在，把你的篮球判断交给九张卡，看看这位原创球星能走多远。

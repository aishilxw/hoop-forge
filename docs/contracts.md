# API contract — v0.3

Current types in src/contracts/index.ts take precedence over this overview. v0.3 adds live quarter plans, persisted activeMatch, FT/foul events, age/condition and retirement commands; see docs/rules.md and docs/iteration-v03.md.
src/contracts/index.ts is the source of truth. Domain exports createCareer(seed:number,catalog:Catalog):Result<CareerState>, applyCommand(state:CareerState, command:GameCommand,catalog:Catalog):Result<CareerState> from src/domain/index.ts. Simulation export simulateMatch(input:MatchInput):MatchResult. Domain owns reward, lifecycle and RNG. UI root component is src/views/GameView.vue with prop api:GameAPI. api is a reactive Pinia store passed from Lead's App.vue. Use api.execute(payload) only; no extra commandId/revision on UI. Data exports catalog from src/data/catalog.ts. All timestamps are metadata outside simulation. Request Lead for contract changes. MatchResult.reward is calculated from actual box score. Initial fixture is allowed only if prominently labeled and never claimed full NBA roster.

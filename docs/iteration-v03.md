# v0.3 重点比赛迭代

## 交付目标

- 每季8场自动重点常规赛，第1/11/22/33/44/55/66/77场；其他比赛可主动观战，所有场次仍可快速模拟。
- 节间决定进攻、防守、节奏、轮换、原创球员时间预算与重点球员。
- 球场与投篮路线、比分走势、单节比分、事件播放基于真实模拟事件，不额外捏造得分。
- 战术收益有代价；节奏影响双方与体能，不提供无条件必赢选项。
- 位置平衡与能力权重轮换、罚球与个人犯规、六犯离场、比赛内体能、主客与休息影响。
- 新季年龄/成长/衰退，主动退役；真实NBA球员未来交易和名单仍不编造。
- 兼容旧版生涯，已完成比赛保持原统计；暂停/刷新不重新抽种子、不重复奖励。

## 验证原则

- 得分=2×FGM+3PM+FTM；罚球命中≤出手；上场分钟和球队比分守恒。
- 同seed/相同前缀计划，不同后续计划不能改变已经进行的节。
- Q1–3不结算，Q4及加时完成后只结算一次；中途存档恢复正常。
- 球场是战术示意，不冒充真实轨迹、直播或3D物理引擎。
- 数值是游戏设计与趋势验证，不声称已拟合真实NBA统计。规则参考NBA官方Rule3及Rule5。

参考：https://official.nba.com/rule-no-3-players-substitutes-and-coaches 、https://official.nba.com/rule-no-5-scoring-and-timing 。

# v0.3.1 DeepSeek 接入验收

日期：2026-10-30。

## 实现

- 用户指定DeepSeek V4.1 Flash，按官方文档使用`deepseek-flash`，当前别名对应V4.1 Flash系列。
- 本机服务转发到官方`api.deepseek.com/chat/completions`，JSON模式、关闭思考模式、最多4000输出token、55秒超时。
- 点击前说明数据发送范围。仅发送已结算比赛的精简事实、当前能力和成长；不将隐藏卡片或未完成回合交给模型，不由模型决定比赛结果。
- 报告含正文、下阶段建议及可展开的事实依据；原统计页保留。每条引用必须存在，结构不合格不展示。
- 同进程相同材料去重与缓存；浏览器IndexedDB独立保存AI正文，刷新同范围可直接阅读。没有自动付费重试。
- 密钥在项目之外的本机私有配置文件，目录700、文件600；没有进入前端、源码、报告或发布包。可用环境变量或试玩包旁的自有`.env.local`配置。

## 实际验证

- 官方模型列表请求HTTP200，含`deepseek-flash`。真实报告生成请求已完成，不是固定文案或本地模板冒充。
- 初次跨赛季报告被引用数上限误拒绝。捕获的真实响应有一节引用7条，均为有效事实；改为按实际事实数量限制并保留逐条存在性校验，补了回归测试。
- 首次成功正文仍把跨季累计写成单季；增加逐季完赛状态、场数和胜负，明确单季常规赛最多82场，更新提示词和缓存版本使旧正文失效。
- 最终真实浏览器报告正确区分：第1季101场（82常规赛+19季后赛），74胜27负；第2季1场，0胜1负，尚未归档；累计102场，74胜28负。正文说明总决赛1–4止步及下阶段可执行的打法/战术/能力建议。
- 展开“分析依据”能查看逐季边界、累计统计及赛季归档。刷新后显示“已读取本机保存的报告，本次未调用模型”，正文与生成时间保留。
- 桌面1280宽和手机390×844已截图检查，恢复默认视口。没有用真实Windows或完整断网环境测试。另实际运行无密钥试玩包，基础页面200、AI状态configured=false、外部来源请求403；浏览器切换第二季后AI按钮禁用并说明配置缺失，下方统计仍正常显示。
- 共55项测试、9文件通过。新增覆盖已完成回合边界、逐季事实、缓存、调用去重、合法多引用、错误引用拒绝、密钥缺失、余额/鉴权/频率错误、截断响应、来源与请求类型、UTF-8跨块处理。构建和格式检查通过。
- 扫描源码及构建文件，实际密钥匹配0处；压缩包另做内容核查。没有输出认证头或密钥到应用日志。

## 边界

自然语言的全部语义不能由格式与引用校验保证。页面明确AI观点可能偏差、以统计为准。模型调用不是免费额度，费用由配置密钥所属账户承担；未统计全部诊断请求的实际账单，不编造费用。

当前只完成AI生涯故事，节间AI助理教练尚未实现。AI正文在本浏览器缓存中，未随生涯JSON备份迁移。NBA名单与评分原有partial缺口没有借AI补造。GitHub未发布。

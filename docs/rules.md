# 当前规则 v0.3.0

此文件取代v0.1短赛季方案。原plan.md仅保留设计历史，不能据此恢复模板队、12场或三季结束。

1. 30支NBA球队，现实球员名单冻结为2026-10-29逐队来源。521人/30队、全部中文。真实性缺口见data-methodology和qa/current-status。
2. 自创球员创建时自由选队，加入当前真实名单。比赛只用该队真实球员及自创球员，不生成虚构队友。
3. 开局5明星+15非明星，20人不重复；九张不同卡各贡献一维。
4. 创建/继承候选属性、总评、提升预览隐藏；不按能力排序。来源确认后才揭晓；初始确认前不展示原创球员雷达/数值。
5. 盲继承消耗整卡，当前值取max(当前,来源)，无提升也消耗，不降级。确认前说明风险。
6. 训练成本、卡包价格、九维范围统一由config/balance维护，UI不得复制逻辑。
7. 每队82场常规赛，41主41客，共1230场；同赛区4次，同联盟非赛区6队4次/4队3次，跨联盟2次。
8. 赛程按NBA频次生成并明确标记，不能称官方逐日表；主客顺序打散，不能开局全主场。
9. 30队所有比赛推进并进入排名；不能给其他球队随机捏造胜场。排名按胜率及NBA同战绩规则。
10. 前6直接晋级；7/8争7号，9/10败者淘汰，余者争8号；附加赛数据单列。
11. 东西各8队固定对阵、四轮七局四胜，总决赛2-2-1-1-1主场顺序；淘汰后仍计算联盟冠军。
12. 生涯可继续后续赛季，不在第三季强制结束；未来赛季沿用冻结名单，不假称真实未来交易。
13. 生涯报告在游戏内阅读，含常规赛/附加赛/季后赛拆分、效率、代表比赛、逐轮结局、逐季记录与成长。
14. JSON仅为备份，不能代替生涯报告。用户已授权DeepSeek接入；AI故事主动生成，统计分析独立保留，密钥仅在本机服务。
15. schemaVersion2、rulesVersion0.3.0。v0.2迁移保留历史赛果、金币和进度，补年龄和状态。旧v1存档保留，不能伪装真实NBA历史。
16. IndexedDB事务同时保存活动档和备份，Web Locks控制并发，BroadcastChannel同步。
17. 导入必须校验联盟比分/球队/排名和个人记录一致，失败不替换当前档。
18. domain纯函数、固定种子、事件产生统计；禁止Vue/DOM/网络/系统随机数进入模拟。
19. 全部源码/测试统一Prettier；一次文件一个写入者，公共契约由Lead维护。
20. 正式GitHub发布仍待本地审核。不得把partial名单、估计评分、未测平台宣称为已全量验证。

21. 每季第1/11/22/33/44/55/66/77场常规赛自动重点提示，其他场次也可观战。允许快速模拟。
22. 按节选择进攻、防守、节奏、轮换、26/32/38分钟预算与本队重点球员。相同种子与已执行计划保证相同历史前缀，未来计划不得改写过去。
23. 只保存已完成节；前三节不结算个人赛果与金币，第四节及必要加时完成后仅结算一次。回放期间比分/走势不展示未播放事件，累计统计在当前节回放结束后揭晓。
24. 得分=2×FGM+3PM+FTM，分钟非负。六犯离场及位置轮换参与计算；罚球规则是简化模型，并非完整NBA裁判引擎。
25. 球场是战术示意，不是真实NBA直播或真实运动轨迹。
26. 新建球员19岁，休赛期恢复并记录成长或衰退，可主动退役。120岁为程序边界，不是NBA退役规则。

27. AI教练只接收赛前/已完成节信息，不发送未来回合或种子；推荐计划需通过枚举、分钟预算和本队候选校验。采用只填入战术板，由玩家执行；下一节开始旧建议失效。
28. 同一DeepSeek密钥支持报告与教练，不训练权重。调用用量按返回值记录，未知不可标零。重复缓存阅读不请求模型；小样本省token对照不能宣传成普遍省费保证。
